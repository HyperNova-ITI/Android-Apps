# HyperNova Phone ↔ NOVA Backend Master Plan

This file is generated by `hypernova_phone_finish_backend.sh`.

## Ownership

```text
NOVA AI
  - speech / NLU
  - dialogue context
  - pronouns / ordinals
  - candidate selection / clarification
        |
        | AIDL Binder
        v
HyperNova Phone
  - HFP readiness
  - ContactsProvider
  - CallLog
  - Android Telecom
  - confirmed call/audio state
```

## Implemented by the master script

- `getCurrentState()`
- `searchContacts(query, limit)`
- `getContact(contactId)` with real `Phone._ID` number IDs
- `getCallHistory(filter, limit)`
- `getCallHistoryForContact(contactId, filter, limit)`
- exact `MISSED != REJECTED` call-history semantics
- `callContact(contactId, numberId)`
- `callNumber(phoneNumber)`
- `callHistoryEntry(callId)`
- `answerCall()`
- `declineCall()`
- `endCall()`
- idempotent `setMuted(true/false)`
- idempotent `setHeld(true/false)`
- `setAudioRoute(VEHICLE/PHONE/BLUETOOTH)`
- `sendDtmf(0-9/*/#)`
- real-time `IPhoneStatusCallback`
- request-ID deduplication using the shared contract TTL
- `STATUS_ACCEPTED` followed by one terminal result for dispatched commands
- terminal success only after Android state confirmation where confirmation exists

## Deliberately not changed

The master script does **not** edit:

```text
telecom/HyperNovaInCallService.kt
telecom/TelecomCallController.kt
```

The existing real Telecom implementation is reused as-is.

## Scenario mapping

```text
"Call Youssef"
    -> searchContacts("Youssef")
    -> getContact(contactId)
    -> callContact(contactId, numberId)

"Who were my last missed calls?"
    -> getCallHistory(MISSED, limit)

"How many times did Youssef call?"
    -> getCallHistoryForContact(contactId, ALL, limit)

"Call the last person who called me"
    -> getCallHistory(INCOMING, 1)
    -> callHistoryEntry(callId)

"Redial"
    -> getCallHistory(OUTGOING, 1)
    -> callHistoryEntry(callId)

"Answer"
    -> answerCall()

"Decline"
    -> declineCall()

"End the call"
    -> endCall()

"Mute / unmute"
    -> setMuted(true / false)

"Hold / resume"
    -> setHeld(true / false)

"Audio to phone / vehicle / Bluetooth"
    -> setAudioRoute(...)

"Press 1"
    -> sendDtmf("1")
```

## Runtime validation still required

A successful Gradle build proves source/AIDL integration only.

Runtime validation on AAOS still needs:

1. Install/bake the updated Phone APK.
2. Confirm `READ_CONTACTS`, `READ_CALL_LOG`, `CALL_PHONE`, HFP and Dialer/InCallService policy.
3. Use a small Binder contract test client in place of NOVA.
4. Test real contacts and multiple-number selection.
5. Test missed/incoming/outgoing/rejected CallLog filters.
6. Test outgoing call and redial.
7. Test incoming answer/decline.
8. Test end/mute/hold/audio/DTMF.
9. Re-send the same `requestId` and verify no command executes twice.
10. Connect NOVA to the same shared contract after the Phone side passes.

## Context priority retained for NOVA

```text
Current real-world Phone event
    >
Current explicit conversation selection
    >
Recent candidate list
    >
Older conversation context
```

The Phone app never interprets natural-language phrases such as "him", "the second one", or "call Youssef". It receives only structured AIDL requests.
